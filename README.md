# Twenty Questions

A Java-based Twenty Questions game where the user answers a series of questions and the program attempts to determine what they are thinking of.

## Features

* Interactive question-and-answer gameplay
* User input and conditional logic
* Keeps track of the questions and responses
* Provides a final guess based on the user's answers

## Technologies

* Java

## What I Learned

This project helped me practice Java programming, conditional statements, user input, and problem-solving. It also gave me experience designing a program around user interaction and decision-making.
